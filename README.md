# 🎬 Netflix Clone

A Netflix-inspired streaming website built using **HTML, CSS, and JavaScript**. This project recreates the look and feel of Netflix with a dark theme, movie sections, search functionality, and an interactive watchlist.

## ✨ Features

- 🎥 Netflix-inspired user interface
- 🌑 Dark theme and responsive layout
- 🔥 Trending and popular movie sections
- 🔍 Search functionality for movies
- 📋 My List feature to save favorite movies
- 💾 Local Storage to preserve your watchlist
- 🖼️ Movie posters and a featured hero banner
- 📱 Responsive design for different screen sizes
- 🪟 Interactive movie details modal

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layout, and responsiveness
- **JavaScript** — Interactivity and functionality
- **Local Storage** — Saving the watchlist in the browser

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/netflix-clone.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code.

## 📌 Important Notes

- This is a front-end learning project inspired by Netflix.
- It is not affiliated with or endorsed by Netflix.
- Movie images may load from external image URLs, so an internet connection may be required.
- Actual video streaming and Netflix account authentication are not implemented.
